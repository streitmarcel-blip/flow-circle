# Changelog

All notable changes to the "Flow Circle" project will be documented in this file.

## [0.9.0] - 2026-01-20 (MVP)

### Added
- **Core App Shell**: Responsive Layout with Header and Footer.
- **Circular Timer**: SVG-based timer with "Deep Space" glow effects.
- **Task Management**: Create tasks with titles, duration, and descriptions.
- **Timeline**: Vertical visualization of daily blocks.
- **Data Persistence**: Tasks are saved to browser `localStorage`.
- **Audio System**: Procedural "Soft Gong" sound on timer completion.
- **PWA Support**: `manifest.json` and service worker configuration for offline use.
- **Theme Support**: CSS Variable based implementation of "Deep Space Calm" (Dark) and "Soft Light" (Light) modes.

### Fixed
- Mobile overflow issues on the main dashboard.
- Reverted color palette to original "Deep Space" specification after accidental shift.

### Known Issues
- Input field focus bug on Chrome Android.
- "Flow" button wording needs update to "Start".
