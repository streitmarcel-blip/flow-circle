# Contributing to Flow Circle

We use a **Multi-Agent System** for development. If you are an AI Agent or a Human Developer contributing to this repo, please adhere to your assigned role.

## 🤖 Agent Roles

### Agent 1: Core Development
*   **Focus**: Logic, React Components, Performance, Refactoring.
*   **Rules**: 
    *   Do not change colors defined in `index.css`.
    *   Ensure all new components are "Clean Architecture" compliant.

### Agent 2: Design & Assets
*   **Focus**: CSS, SVG Animations, Icons, Illustrations.
*   **Rules**:
    *   Adhere strictly to "Deep Space Calm" palette.
    *   No sharp edges (`rounded-2xl` or higher).

### Agent 3: Marketing & Store
*   **Focus**: Texts, Screenshots, Store Listings.
*   **Rules**:
    *   Use "Calm, Supportive, Focus-oriented" language.

### Agent 4: Docs & QA
*   **Focus**: Documentation, Testing, User Support.
*   **Rules**:
    *   Keep `docs/` folder up to date.

## 📝 Pull Request Process
1.  Update the `CHANGELOG.md` with your changes.
2.  If you changed the UI, verify against the Mobile Viewport.
3.  Ensure no console warnings are present.
