# Project Definition: Flow Circle (ADHD Focus)

**Status**: ACTIVE SOURCE OF TRUTH
**Gilt für**: Alle Agenten (Dev, Design, Marketing, Support)

## 🧠 Core Philosophy (Der "North Star")
Die App ist ein **Rückzugsort** für das Gehirn, kein Rummelplatz. Sie ist speziell für Menschen mit ADHS oder Reizüberflutung (Sensory Overload) konzipiert.

### ✅ DOs (Das Ziel)
*   **Beruhigend**: Sanfte Farben, weiche Übergänge.
*   **Klarheit**: Viel Whitespace (oder Darkspace), klare Hierarchien.
*   **Pastell**: Nutzung von entsättigten, harmonischen Pastelltönen.
*   **Stille**: Animationen sind langsam und dienen der Orientierung, nicht dem Effekt.
*   **Fokus**: Nur eine Hauptaktion pro Bildschirm.

### ❌ DON'Ts (Verboten)
*   **Kein Neon**: Keine grellen, aggressiven Farben (Cyan, Neon-Pink, Bright Lime).
*   **Kein Stress**: Keine blinkenden Elemente oder hektischen Countdowns.
*   **Kein Clutter**: Keine überflüssigen Dekorationen oder "Gamification"-Badges, die ablenken.

## 🎨 Design-Vorgaben (Global)
*   **Palette**: "Deep Space Calm". Ein sehr dunkles, fast schwarzes Blau/Grau als Basis. Akzente in Pastell-Lila, Salbei-Grün, Mond-Gelb.
*   **Typografie**: Lesbar, rund, freundlich (z.B. 'Outfit' oder 'Nunito').
*   **Haptik**: Weich, abgerundet (Rounded Corners überall).

## 🤖 Anweisungen pro Agent

### Agent 1 (Dev)
*   Vermeide hektische Transitionen.
*   Implementiere "Reduced Motion" standardmäßig respektvoll.
*   Keine aufdringlichen Popups.

### Agent 2 (Design)
*   Erstelle Assets, die *visuelle Stille* ausstrahlen.
*   Nutze Noise-Texturen oder weiche Verläufe statt harten Kanten.

### Agent 3 (Marketing)
*   Wording: "Entspannung", "Klarheit", "Dein Rhythmus".
*   Vermeide Begriffe wie "High-Speed", "Extreme Productivity", "Hustle".
