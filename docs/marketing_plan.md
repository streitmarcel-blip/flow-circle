# Marketing Strategy: Flow Circle

**Agent 3 Focus**: Launch Preparation & Store Presence

## 🎯 Brand Identity
*   **Name**: Flow Circle
*   **Vibe**: Beruhigend, Organisch, "Endless Loop", Weicher Fokus.
*   **Core Value**: Struktur ohne Stress. Ein Planer, der dich atmen lässt.
*   **Visual Style**: Soft Mode First. Sanfte Pastell-Verläufe auf dunklem Grund. Keine harten Kontraste.

## 🔑 ASO Strategy (App Store Optimization)
*   **Keywords**: *Adhd Planner, Gentle Productivity, Mindful Planning, Sensory Friendly, Daily Routine, Pastel Design.*
*   **Platform**: Web (PWA) primär, Play Store sekundär (via TWA).

## 📄 Deliverables Plan (Agent 3)

### 1. Store Listing (`store_listing.md`)
*   **App Title**: Muss "Flow Circle" + Key-Feature enthalten.
*   **Short Description**: 80 Zeichen Pitch (Catchy & Clear).
*   **Long Description**:
    *   Intro (Emotional Hook)
    *   Key Features (Bullet Points)
    *   Social Proof & Call to Action
    *   *SEO-fokussiert*.

### 2. Visuals Plan (`visuals_plan.md`)

    4.  **Settings/Theming**: ("Your Universe").
*   **Feature Graphic**: Banner für den Store (1024x500).
